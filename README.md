# FM Exporter

*[English below](#english)*

Plugin BepInEx per **Football Manager 26** (Windows, Steam) che estrae i dati dal gioco con un tasto:

| Tasto | Cosa fa |
|---|---|
| **F8** | Aggiorna tutto: rosa, tattica, data del gioco, contratti, lista selezionati, Database giocatori e budget |
| **F9** | Esporta un'intera lista di giocatori in CSV e HTML |
| **F11** | Aggiunge tutti gli attributi, presenze e media voto alla vista della lista |
| **F10** | Legge gli attributi chiave e preferiti dei ruoli, la tattica o i budget |
| **F7** | Legge le valutazioni del gioco dal profilo di un giocatore |

I dati si leggono con [FM Valutatore](https://github.com/Zichi90123/fm-valutatore).

## Scaricare e installare

1. Scarica `FMExporter-x.y.z.zip` dall'[ultima release](https://github.com/Zichi90123/fm-exporter/releases/latest).
2. Apri `LEGGIMI.md` dentro lo zip e segui i passi: installazione di BepInEx, le due correzioni per FM26, primo avvio e installazione del plugin.

Per aggiornare basta estrarre lo zip della nuova versione nella cartella di FM26, **a gioco chiuso**.

Questo repository contiene solo le release: il codice sorgente è privato.

## English

BepInEx plugin for **Football Manager 26** (Windows, Steam) that exports game data with a key press: F8 updates everything, F9 exports a player list to CSV and HTML, F11 adds all attributes to the list view, F10 reads role key attributes, tactics or budgets, F7 reads the game's ratings from a player profile. The data is read by [FM Valutatore](https://github.com/Zichi90123/fm-valutatore).

1. Download `FMExporter-x.y.z.zip` from the [latest release](https://github.com/Zichi90123/fm-exporter/releases/latest).
2. Open `README.md` inside the zip and follow the steps: BepInEx installation, the two FM26 fixes, first launch and plugin installation.

To update, extract the new zip into the FM26 folder **with the game closed**.

This repository only hosts releases: the source code is private.
